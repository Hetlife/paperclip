## Task 2.1 — discovery call script (done ahead of schedule)

Drafted `templates/discovery-call-script.md`. This doesn't need to wait
for Gate 1 to be written — it costs nothing to prepare and the founder
should have it ready before the first call. The script itself does need
to wait for Gate 1 to be *used* — explicitly noted in both the file and
`goal-and-tasks.md` so nobody mistakes "drafted" for "go ahead and call."

Script structure: 7 ordered questions (current source → what would
prompt a switch → order size → payment terms → DOA expectations →
soft trial-order ask), explicit instructions not to pitch price or
species availability (neither is ready yet), and a logging section tied
directly to `buyer-log.csv`'s columns so the founder isn't inventing a
format mid-call.
